# Multi-Agent RAG Support Assistant with Evaluation Pipeline and LLM Latency Optimization

## Goal

Build a production-oriented AI support assistant that combines Retrieval-Augmented Generation (RAG), multi-agent orchestration, automated evaluation, observability, and LLM latency optimization.

The system will provide grounded support responses from a knowledge base while measuring answer quality, retrieval performance, token usage, and latency. The project will also investigate optimization techniques such as caching, model routing, retrieval optimization, parallel execution, and prompt optimization to improve overall system performance.
